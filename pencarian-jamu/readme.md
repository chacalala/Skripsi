# Pencarian Jamu Tradisional Madura

## Deskripsi
Sistem pencarian jamu tradisional Madura berdasarkan keluhan pengguna menggunakan metode N-Gram dan Cosine Similarity.

## Metode
- Preprocessing (cleaning, case folding, tokenizing, stopword removal, stemming)
- N-Gram (n = 1 sampai 5)
- TF-IDF
- Cosine Similarity


## Cara Menjalankan

```bash
pip install -r requirements.txt
streamlit run app.py
